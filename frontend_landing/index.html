The Architecture

How Sabbalens Works

A purpose-built data pipeline designed specifically for photographers and digital media teams.

01

Ingest & Parse

Drag RAW (ARW, CR3, DNG) or JPEG files into the filmstrip. Pillow extracts binary EXIF tags (shutter, aperture, ISO, lens model) instantly in parallel.

POST /api/v1/photos/upload
02

Reverse-Geocode

GPS coordinates are translated into structured locations (City, State, Country) via OpenStreetMap with automated cache protection.

GET /api/v1/photos/{id}/geocode
03

Studio Staging

Review your photo in the focus-reticle stage, inspect Leaflet mini-map pins, and preview the live Telegram chat bubble simulator.

GET /app/ (Studio Workstation)
04

Telegram Dispatch

APScheduler dispatches photos directly to your Telegram channel or group using direct multipart streaming with HTML formatting.

POST /api/v1/photos/{id}/publish

Developer Interface

Command-Line & REST API

Fully scriptable via standard HTTP multipart requests. No complex OAuth handshakes.

# 1. Ingest photo with parallel EXIF extraction

curl -X POST http://localhost:8000/api/v1/photos/upload \

-F "file=@DSC08921.jpg" \

-F "caption=Sunset at the coast" \

-F "destinations=telegram"

# 2. Trigger instant Telegram dispatch

curl -X POST http://localhost:8000/api/v1/photos/1/publish
